{% comment %} Accessible text fallback for a Chart.js canvas (Phase 6 a11y remediation). Two usage modes, selected by which variables are set: 1. Row series - chart_data_rows: a list of {label, value} dicts, as used for trend charts (semester/attendance/date trends). 2. Column series - chart_data_columns: a list of item labels together with chart_data_values: a parallel list of numbers, as used by bar and doughnut charts whose data is stored as parallel lists. Shared options: - chart_data_caption: visible summary text for the details/summary element. - chart_data_item_header / chart_data_value_header: column titles. - chart_data_series_name: row title in column mode. - chart_data_suffix: unit appended to each value, e.g. "%". Values come from the same context objects that drive the charts; nothing is invented here. When Chart.js is unavailable, JavaScript is disabled or a screen reader is used, the same numbers are readable as a table. {% endcomment %} {% if chart_data_rows %}
